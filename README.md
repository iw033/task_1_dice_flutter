# Dice Game App 🎲

A Flutter-based game developed for the Mobile Development course.

## 📱 Project Screenshot

![Dice Game App Screenshot](Project.png)

## ✨ Features
- **Roll Dice:** Generates two random numbers from 1 to 6.
- **Dynamic Feedback:** If total >= 10, shows an image; otherwise, shows another different image.
- **Reset Button:** Resets dice values to 1.
- **Dark Theme:** Styled with a clean modern dark mode.
